# Divergent lens

Read the session transcript at `<TRANSCRIPT_PATH>`. The other two reviewers are looking for wrong
decisions and missing checks. **You are looking for what nobody questioned.**

Answer:

- **The unexamined premise.** What did every turn of this session take for granted? State it, then
  state what would be true instead if it were wrong.
- **The road not taken.** Name a materially different approach that was never put on the table, and
  say in one line why it might have been better. Not a point fix inside the chosen approach — a
  different shape.
- **The silent cost.** What did this session spend the most time on, and was that where the value
  was? Cite the stretch of transcript.
- **The unasked question.** What should have been asked of the user and was not? Distinguish a
  genuine fork from a detail with an obvious default.
- **The work that should not have happened at all.** Anything built that an existing asset already
  did. Name the existing asset.

Be willing to conclude the session was sound and return little. A manufactured divergent finding is
worse than none, because it costs review attention to dismiss.

Return one block per heading, each with a transcript citation. Say "nothing" under any heading with
nothing real.
