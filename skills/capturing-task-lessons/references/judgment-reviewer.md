# Judgment lens

Read the session transcript at `<TRANSCRIPT_PATH>`. You are looking for **decisions that were wrong
at the moment they were made**, not for things that merely turned out badly.

For each candidate, answer:

- **What was decided**, and at roughly which point in the session.
- **What information was already available** that should have pointed the other way. Quote it.
- **What rule, stated in advance, would have produced the right decision.** One imperative line. If
  you cannot write that line, this is not a lesson — drop it.
- **Would the rule have fired more than once?** Cite a second moment in this transcript, or say it
  fired once.

Specifically hunt for:

- work redone because an earlier check proved less than it appeared to
- a correction from the user that reveals a standing preference, not a one-off
- an assumption carried for several turns before being tested
- a decision taken on the user's behalf without asking first
- scope that widened without being named

Reject anything that is hindsight-only: if the information needed to decide correctly did not exist
at the time, say so and drop it.

Return one block per finding: what / evidence with a quote / the candidate rule / how often it
would fire. At most 6 findings. Fewer, sharper findings beat a long list.
